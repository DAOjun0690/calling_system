# 叫號系統 calling_system

- 功能: 一個叫號系統，畫面大小控制在一個螢幕內顯示，右邊不會有y軸滾動軸
- 網站標題：系統自定義使用標題
- 底下有十個櫃台，上方點該櫃臺的號碼1~10號的文字
- 櫃台上面有數字，其中1~8號櫃台數字從0開始，9、10號櫃台從1000號開始，櫃台可以點擊，每次點擊，櫃台的數字會加1，1~8櫃台、9~10櫃台背後使用各自的總點擊數，但只有點擊的櫃檯才會更新櫃台數字
- 1~8號櫃台與9、10號櫃台 樣式要做出區隔，1~10號櫃台長寬要一樣
- 有一個大的提醒標題顯示，文字是 "當前號碼與櫃台： 請1號來賓到1號櫃台"
- 每次點擊櫃台，都會有瀏覽器的文字轉語音，文字是提醒標題內的文字
- 有一個緊急插播的文字輸入框，如果該緊急插播文字輸入框有數字，點櫃台 櫃台與提醒標題會顯示緊急插播的數字，該數字不列入櫃台共用點擊數
- 有三個功能按鈕，分別是「重新播放提醒標題」、「停止播放提醒標題」、「點擊數歸零」
- 有一個控制音量大小的拉吧
- 畫面左下方有一個輸入框，可以設定1~8櫃台點擊數初始值、9~10櫃台的點擊數初始值，這個輸入框在滑動視窗裡面，要點開在網頁左邊的初始設定按鈕才會滑動出來顯示，再點一下初始設定按鈕會滑動回去 
- 有一個小的數位時鐘，顯示當前時間 時分秒
- 櫃台與提醒文字可以大一點，按鈕與音量調整小一點，畫面盡量占滿整個螢幕
- 畫面整體style樣式要正經中帶一點點活潑的感覺
